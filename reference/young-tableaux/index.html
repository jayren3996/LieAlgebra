Young tableaux¶

The Young-tableau toolkit for many-body wavefunctions: tableaux and their tensor form, the Young symmetrizer, inner products, normalization, and orthogonalization of degenerate weight spaces.

Tableau¶

Tableau[rows]

A Young tableau given as a list of row-lists. Used to specify the Young symmetrizer applied by TableauPermute.

Arguments

Argument

Description

rows

a list of rows, e.g. {{1, 2}, {3}}

Examples

In[1]:=
Tableau[{{1, 2}, {3}}]
Out[1]=
Tableau[{{1, 2}, {3}}]
In[2]:=
TableauPermute[Tableau[{{1, 2}, {3}}], Psi[1, 2, 3]]
Out[2]=
Psi[1, 2, 3] + Psi[2, 1, 3] - Psi[2, 3, 1] - Psi[3, 2, 1]

See also: TableauPermute · TensorTableau · Guided tour

TensorTableau¶

TensorTableau[rows]

A tensor-product Young tableau with explicit index entries – a compact notation for a many-body wave function that also displays its permutation symmetry. Linear combinations of TensorTableau expressions are the working objects of the toolkit.

Arguments

Argument

Description

rows

a list of rows of index entries, e.g. {{1, 2}, {3}}

Examples

In[1]:=
TensorTableau[{{1, 2}, {3}}]
Out[1]=
TensorTableau[{{1, 2}, {3}}]
In[2]:=
ToTensor[TensorTableau[{{1, 2}, {3}}]]
Out[2]=
Psi[1, 2, 3] + Psi[2, 1, 3] - Psi[2, 3, 1] - Psi[3, 2, 1]

See also: ToTensor · TableauForm · TableauDot · TableauNormalization · Tutorial: Young tableaux

TableauForm¶

TableauForm[t]

Displays a TensorTableau (or a linear combination of them) as a labelled Young-tableau grid. This is a display form; use ToTensor to get the same state as data.

Arguments

Argument

Description

t

a TensorTableau or linear combination

Examples

In[1]:=
TableauForm[TensorTableau[{{1, 2}, {3}}]]

renders as a labelled Young-tableau grid in the notebook front end (top row 1, 2; second row 3). The same state, as data:```{raw} html

```
In[2]:=
ToTensor[TensorTableau[{{1, 2}, {3}}]]
Out[2]=
Psi[1, 2, 3] + Psi[2, 1, 3] - Psi[2, 3, 1] - Psi[3, 2, 1]

See also: TensorTableau · ToTensor

TableauPermute¶

TableauPermute[t, v]

Applies the Young symmetrizer of the tableau t to a basis tensor v, giving the (unnormalized) wave function as a combination of Psi tensors. A repeated entry within a column makes the result vanish, since columns are antisymmetrized.

Arguments

Argument

Description

t

a Tableau giving the symmetry

v

a Psi basis tensor

Examples

In[1]:=
TableauPermute[Tableau[{{1, 2}, {3}}], Psi[1, 1, 2]]
Out[1]=
2*Psi[1, 1, 2] - Psi[1, 2, 1] - Psi[2, 1, 1]

See also: Tableau · Psi · ToTensor

TableauNormalization¶

TableauNormalization[t]

Normalizes a TensorTableau expression to unit norm.

Arguments

Argument

Description

t

a TensorTableau or linear combination

Examples

In[1]:=
TableauNormalization[TensorTableau[{{1, 2}, {2}}]]
Out[1]=
TensorTableau[{{1, 2}, {2}}]/Sqrt[6]

See also: TensorNorm · TableauDot · TableauOrthogonalization

TableauOrthogonalization¶

TableauOrthogonalization[t1, t2]

One Gram-Schmidt step: returns {t1, t2 - <t2,t1>/<t1,t1> t1}, keeping t1 and orthogonalizing t2 against it. Used to pick a basis for a degenerate (repeated) weight space.

Arguments

Argument

Description

t1

a TensorTableau expression to keep

t2

a TensorTableau expression to orthogonalize against t1

Examples

In[1]:=
TableauOrthogonalization[2 TensorTableau[{{1, 2}, {3}}] - TensorTableau[{{1, 3}, {2}}], TensorTableau[{{1, 3}, {2}}] + TensorTableau[{{1, 2}, {3}}]]
Out[1]=
{2*TensorTableau[{{1, 2}, {3}}] - TensorTableau[{{1, 3}, {2}}], 
 (3*TensorTableau[{{1, 3}, {2}}])/2}

See also: TableauDot · TableauNormalization · Guided tour: orthogonalizing a degenerate weight

TableauDot¶

TableauDot[t1, t2]

The inner product of two TensorTableau expressions.

Arguments

Argument

Description

t1

a TensorTableau expression

t2

a TensorTableau expression

Examples

In[1]:=
TableauDot[TensorTableau[{{1, 2}, {3}}], TensorTableau[{{1, 2}, {3}}]]
Out[1]=
4

See also: TensorDot · TableauNormalization · TableauOrthogonalization

ToTensor¶

ToTensor[t]

Converts a TensorTableau (or linear combination) into an explicit linear combination of Psi basis tensors.

Arguments

Argument

Description

t

a TensorTableau or linear combination

Examples

In[1]:=
ToTensor[TensorTableau[{{1, 2}, {3}}]]
Out[1]=
Psi[1, 2, 3] + Psi[2, 1, 3] - Psi[2, 3, 1] - Psi[3, 2, 1]

See also: TensorTableau · Psi · TableauPermute

TensorDot¶

TensorDot[p1, p2]

The Hermitian inner product of two linear combinations of Psi tensors. Distinct basis tensors are orthonormal.

Arguments

Argument

Description

p1

a linear combination of Psi tensors

p2

a linear combination of Psi tensors

Examples

In[1]:=
TensorDot[Psi[1, 2, 3], Psi[1, 2, 3]]
Out[1]=
1
In[2]:=
TensorDot[Psi[1, 2], Psi[2, 1]]
Out[2]=
0

See also: TableauDot · TensorNorm · Psi

TensorNorm¶

TensorNorm[p]

The norm of a linear combination of Psi tensors, i.e. Sqrt[TensorDot[p, p]].

Arguments

Argument

Description

p

a linear combination of Psi tensors

Examples

In[1]:=
TensorNorm[Psi[1, 2] + Psi[2, 1]]
Out[1]=
Sqrt[2]

See also: TensorDot · TableauNormalization

Psi¶

Psi[i1, i2, ...]

A basis tensor |i1, i2, …> in the tensor-product space – the elementary building block of the many-body wave functions. Distinct Psi tensors are orthonormal under TensorDot.

Arguments

Argument

Description

i1, i2, ...

the indices labelling the basis tensor

Examples

In[1]:=
Psi[1, 2, 3]
Out[1]=
Psi[1, 2, 3]
In[2]:=
TensorDot[Psi[1, 2], Psi[1, 2]]
Out[2]=
1

See also: ToTensor · TensorDot · TensorNorm · TableauPermute
