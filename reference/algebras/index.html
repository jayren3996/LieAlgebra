Algebras & generators¶

Construct the classical Lie algebras and read off their generators in the standard, Cartan-Weyl, and Chevalley bases.

LieAlgebra¶

LieAlgebra[type, rank]

The canonical constructor for a simple Lie algebra. type is one of the Cartan types and rank is a positive integer. Every algebra in the package normalizes to this form, so SU[n], SO[n], and Sp[n] are convenience wrappers that evaluate to a LieAlgebra[...].

Arguments

Argument

Description

type

the Cartan type: “A”, “B”, “C”, or “D”

rank

a positive integer, the rank of the algebra

Messages

Emits a message and returns $Failed on invalid input.

Message

When

LieAlgebra::badtype

type is not one of “A”, “B”, “C”, “D”

LieAlgebra::badrank

rank is not a valid rank for the given type

Examples

In[1]:=
SU[3]
Out[1]=
LieAlgebra["A", 2]
In[2]:=
LieAlgebra["B", 2]
Out[2]=
LieAlgebra["B", 2]

Notes

  • “A” is su, “B” is so of odd dimension, “C” is sp, and “D” is so of even dimension.

See also: SU · SO · Sp · Rank · CartanMatrix · Concepts: the ABCD classification

SU¶

SU[n]

The special unitary algebra su(n), the type A(n-1) algebra. Shorthand that normalizes to LieAlgebra["A", n-1].

Arguments

Argument

Description

n

an integer >= 2

Messages

Emits a message and returns $Failed on invalid input.

Message

When

SU::baddim

n is not an integer >= 2

Examples

In[1]:=
SU[3]
Out[1]=
LieAlgebra["A", 2]
In[2]:=
SU[3] === LieAlgebra["A", 2]
Out[2]=
True

See also: LieAlgebra · SO · Sp · Generators · Irrep

SO¶

SO[n]

The special orthogonal algebra so(n). Covers both families: type B for odd n >= 3 and type D for even n >= 4.

Arguments

Argument

Description

n

an integer >= 3

Messages

Emits a message and returns $Failed on invalid input.

Message

When

SO::baddim

n is not an integer >= 3

Examples

In[1]:=
SO[5]
Out[1]=
LieAlgebra["B", 2]
In[2]:=
SO[6]
Out[2]=
LieAlgebra["D", 3]

Notes

  • so(odd) and so(even) are different Cartan types (B and D), so their root systems and irreps differ.

See also: LieAlgebra · SU · Sp · Generators · Irrep

Sp¶

Sp[n]

The symplectic algebra sp(n), the type C(n/2) algebra. Defined for even n >= 2.

Arguments

Argument

Description

an even integer >= 2 (the size of the defining representation)

Messages

Emits a message and returns $Failed on invalid input.

Message

When

n is not an even integer >= 2

Examples

In[1]:=
Sp[4]
Out[1]=
LieAlgebra["C", 2]

Sp[4] === LieAlgebra["C", 2]
Out[2]=
True

Generators¶

Generators[g]
Generators[g, "Standard"]
Generators[g, "CartanWeyl"]
Generators[g, "Chevalley"]

The generators of g in one of three bases. The scheme defaults to "Standard" (Generators[g] is Generators[g, "Standard"]): the defining-representation generators, as a list of exact matrices. "CartanWeyl" and "Chevalley" instead return an association with keys "Cartan", "Raising", "Lowering".

Arguments

Argument

Description

g

a Lie algebra, e.g. SU[3]

scheme

optional: “Standard” (default), “CartanWeyl”, or “Chevalley”

Options

Option

Default

Description

"Realization"

"Diagonal"

for so/sp in the Chevalley scheme, selects the Diagonal realization (diagonal Cartan generators) or the Antisymmetric one; ignored for the Standard/CartanWeyl schemes and for su

Messages

Emits a message and returns $Failed on invalid input.

Message

When

Generators::badscheme

the scheme is not “Standard”, “CartanWeyl”, or “Chevalley”

Generators::badrealization

“Realization” is not “Diagonal” or “Antisymmetric” (Chevalley scheme of so/sp)

Examples

In[1]:=
Generators[SU[2]]
Out[1]=
{{{0, 1/2}, {1/2, 0}}, {{0, -1/2*I}, {I/2, 0}}, {{1/2, 0}, {0, -1/2}}}
In[2]:=
Keys[Generators[SU[3], "Chevalley"]]
Out[2]=
{"Cartan", "Raising", "Lowering"}
In[3]:=
Generators[SU[3], "Standard"] === Generators[SU[3]]
Out[3]=
True

Notes

  • The “Realization” option must be given with an explicit scheme, e.g. Generators[g, “Chevalley”, “Realization” -> “Antisymmetric”]; passing it with no scheme is read as the scheme argument (a badscheme error). BasisTransform[g] relates the two Chevalley realizations.

  • The CartanWeyl and Chevalley shorthands take no options; use Generators[g, …] directly to pass “Realization”.

See also: CartanWeyl · Chevalley · BasisTransform · RepresentationMatrices · Concepts: the three bases · Tutorial: getting started

CartanWeyl¶

CartanWeyl[g]

Shorthand for Generators[g, "CartanWeyl"]. Returns the Cartan-Weyl basis as an association: the diagonal Cartan generators ("Cartan"), the raising operators ("Raising"), and the lowering operators ("Lowering").

Arguments

Argument

Description

g

a Lie algebra

Examples

In[1]:=
Keys[CartanWeyl[SU[2]]]
Out[1]=
{"Cartan", "Raising", "Lowering"}
In[2]:=
CartanWeyl[SU[2]]["Cartan"]
Out[2]=
{{{1/Sqrt[2], 0}, {0, -(1/Sqrt[2])}}}

Notes

  • A single-argument shorthand: it takes no options. To choose a realization, call Generators[g, “CartanWeyl”, …] directly.

See also: Generators · Chevalley · Guided tour: Cartan-Weyl basis

Chevalley¶

Chevalley[g]

Shorthand for Generators[g, "Chevalley"]. Returns the Chevalley basis as an association of "Cartan", "Raising", "Lowering" generators, one triple per simple root. This is the basis the representation engine uses; the default (Diagonal) realization has diagonal Cartan generators.

Arguments

Argument

Description

g

a Lie algebra

Examples

In[1]:=
Chevalley[SU[2]]
Out[1]=
<|"Cartan" -> {{{1, 0}, {0, -1}}}, "Raising" -> {{{0, 1}, {0, 0}}}, 
 "Lowering" -> {{{0, 0}, {1, 0}}}|>
In[2]:=
DiagonalMatrixQ /@ Chevalley[SO[5]]["Cartan"]
Out[2]=
{True, True}

Notes

  • A single-argument shorthand: it takes no options. For the Antisymmetric realization of so/sp, call Generators[g, “Chevalley”, “Realization” -> “Antisymmetric”]; BasisTransform[g] maps it to the Diagonal one.

See also: Generators · CartanWeyl · RepresentationMatrices · Guided tour: Chevalley basis

BasisTransform¶

BasisTransform[g]

The change-of-basis matrix conjugating the Antisymmetric realization of an so/sp Chevalley basis into the Diagonal one (u.a.Inverse[u] carries one to the other). For su it is the identity.

Arguments

Argument

Description

g

a Lie algebra

Examples

In[1]:=
BasisTransform[SU[2]]
Out[1]=
{{1, 0}, {0, 1}}
In[2]:=
Dimensions[BasisTransform[SO[5]]]
Out[2]=
{5, 5}

See also: Generators · Chevalley
